# 10. Từ điển thuật ngữ OTA (Glossary)

Sắp xếp theo chữ cái. (EN = tiếng Anh, VN = giải thích)

| Thuật ngữ | Viết đầy đủ | Giải thích |
|---|---|---|
| **ADR** | Average Daily Rate | Giá phòng trung bình mỗi đêm |
| **ADT / CHD / INF** | Adult / Child / Infant | Người lớn / trẻ em / em bé (hàng không) |
| **Affiliate** | — | Đối tác giới thiệu khách nhận hoa hồng |
| **Agency model** | — | OTA hưởng hoa hồng, khách trả nhà cung cấp |
| **Allotment** | — | Số phòng/ghế được giữ cho đại lý |
| **Ancillary** | — | Dịch vụ bán kèm (hành lý, ghế, bảo hiểm…) |
| **AOV / ABV** | Average Order / Booking Value | Giá trị đơn trung bình |
| **APIS** | Advance Passenger Information | Thông tin hộ chiếu khai báo trước cho chuyến quốc tế |
| **ARC** | Airlines Reporting Corporation | Tương đương BSP tại Mỹ |
| **ARR / RevPAR** | Revenue per Available Room | Doanh thu trên mỗi phòng sẵn có (chỉ số khách sạn) |
| **B2B / B2C / B2B2C / B2E** | — | Các mô hình khách hàng (doanh nghiệp, người tiêu dùng, qua đối tác, nhân viên) |
| **BAR** | Best Available Rate | Giá công khai tốt nhất |
| **Bedbank** | — | Kho phòng bán buôn B2B |
| **Billboard effect** | — | Hiệu ứng "biển quảng cáo": khách thấy khách sạn trên OTA rồi đặt trực tiếp |
| **Bleisure** | Business + Leisure | Kết hợp công tác và nghỉ dưỡng |
| **BNPL** | Buy Now Pay Later | Mua trước trả sau |
| **Board basis** | RO/BB/HB/FB/AI | Chế độ ăn kèm phòng |
| **Booking engine / IBE** | Internet Booking Engine | Công cụ đặt chỗ trên website |
| **BSP** | Billing and Settlement Plan | Hệ thống thanh toán của IATA giữa đại lý và hãng |
| **CAC** | Customer Acquisition Cost | Chi phí có một khách mới |
| **Cancellation policy** | — | Chính sách hủy |
| **Channel Manager** | — | Công cụ đồng bộ giá & phòng ra nhiều kênh |
| **Chargeback** | — | Khách đòi lại tiền qua ngân hàng phát hành thẻ |
| **Codeshare** | — | Liên danh hàng không |
| **Commission** | — | Hoa hồng |
| **Connected trip** | — | Toàn bộ chuyến đi được kết nối liền mạch trong một nền tảng |
| **Consolidator** | — | Đại lý gom/xuất vé bán lại cho đại lý khác |
| **CPA / CPC / CPM** | Cost per Acquisition / Click / Mille | Mô hình tính phí quảng cáo |
| **CRS** | Central Reservation System | Hệ thống đặt chỗ trung tâm |
| **CTA / CTD** | Closed to Arrival / Departure | Đóng ngày đến / ngày đi |
| **Cut-off** | — | Hạn chót đặt/giải phóng phòng |
| **DMC** | Destination Management Company | Công ty dịch vụ tại điểm đến |
| **Drip pricing** | — | Hiển thị giá thấp rồi cộng dần phí – hành vi bị cấm/hạn chế ở nhiều nước |
| **Dynamic packaging** | — | Ghép gói linh hoạt theo thời gian thực |
| **Dynamic pricing** | — | Giá thay đổi theo cung cầu |
| **EMD** | Electronic Miscellaneous Document | Chứng từ dịch vụ phụ hàng không |
| **E-ticket** | Electronic ticket | Vé điện tử (13 số) |
| **Extranet** | — | Cổng quản lý cho nhà cung cấp |
| **Fare basis / Fare class / RBD** | Reservation Booking Designator | Mã/hạng giá vé |
| **Fare family / Branded fares** | — | Gói giá có tên và quyền lợi |
| **FIT / GIT** | Free Independent Traveler / Group Inclusive Tour | Khách lẻ / khách đoàn |
| **Float** | — | Tiền khách trả trước OTA đang giữ |
| **Free sale** | — | Bán tự do không cần xác nhận lại |
| **GBV / GMV** | Gross Booking / Merchandise Value | Tổng giá trị giao dịch |
| **GDS** | Global Distribution System | Hệ thống phân phối toàn cầu (Amadeus, Sabre, Travelport) |
| **Guest checkout** | — | Đặt không cần tài khoản |
| **IATA** | International Air Transport Association | Hiệp hội Vận tải Hàng không Quốc tế |
| **Inbound / Outbound / Domestic** | — | Khách vào / ra / nội địa |
| **Instant confirmation** | — | Xác nhận tức thì |
| **Interline** | — | Hợp tác vận chuyển nối chuyến giữa các hãng |
| **IRROPS** | Irregular Operations | Sự cố khai thác bất thường (hoãn/hủy chuyến) |
| **LCC / FSC** | Low-cost / Full-service Carrier | Hãng giá rẻ / truyền thống |
| **LOS** | Length of Stay | Số đêm lưu trú |
| **Look-to-book** | — | Tỷ lệ tìm kiếm trên đặt chỗ |
| **Loyalty** | — | Chương trình khách hàng thân thiết |
| **LTV / CLV** | (Customer) Lifetime Value | Giá trị vòng đời khách |
| **Mapping** | — | Ghép trùng dữ liệu sản phẩm từ nhiều nguồn |
| **Markup** | — | Phần cộng thêm trên giá net |
| **Merchant model** | — | OTA thu tiền trước, tự định giá bán |
| **Merchant of Record (MoR)** | — | Bên đứng tên bán hàng chịu trách nhiệm giao dịch & thuế |
| **Metasearch** | — | Công cụ so sánh giá |
| **MICE** | Meetings, Incentives, Conferences, Exhibitions | Du lịch hội nghị, sự kiện, khen thưởng |
| **MinLOS / MaxLOS** | — | Số đêm tối thiểu / tối đa |
| **NDC** | New Distribution Capability | Chuẩn phân phối trực tiếp của IATA |
| **Net rate** | — | Giá net (giá vốn) |
| **No-show** | — | Khách không đến |
| **NRF** | Non-refundable | Không hoàn hủy |
| **Occupancy** | — | Công suất phòng / số người tối đa trong phòng |
| **On request** | — | Đặt chờ xác nhận |
| **Opaque pricing** | — | Giá ẩn danh nhà cung cấp |
| **Overbooking / Walk** | — | Bán vượt / chuyển khách sang cơ sở khác |
| **Package** | — | Gói du lịch |
| **PAX** | Passenger(s) | Hành khách |
| **PCI DSS** | Payment Card Industry Data Security Standard | Chuẩn bảo mật dữ liệu thẻ |
| **PMS** | Property Management System | Phần mềm quản lý khách sạn |
| **PNR** | Passenger Name Record | Hồ sơ đặt chỗ |
| **Price freeze / Price lock** | — | Trả phí để giữ giá |
| **PSP** | Payment Service Provider | Nhà cung cấp dịch vụ thanh toán |
| **PSS** | Passenger Service System | Hệ thống phục vụ hành khách của hãng bay |
| **Rack rate** | — | Giá niêm yết |
| **Rate parity** | — | Ngang bằng giá giữa các kênh |
| **Rate plan** | — | Gói giá của loại phòng |
| **Reconciliation** | — | Đối soát |
| **Redemption** | — | Sử dụng vé/voucher tại điểm |
| **Refund / Void / Reissue** | — | Hoàn / hủy trong ngày / xuất lại vé |
| **Release period** | — | Thời hạn trả lại allotment chưa bán |
| **RevPAR** | Revenue per Available Room | Doanh thu mỗi phòng sẵn có |
| **RMS** | Revenue Management System | Hệ thống quản trị doanh thu |
| **ROAS** | Return on Ad Spend | Doanh thu trên chi phí quảng cáo |
| **Room night** | — | Một phòng × một đêm |
| **Segment** | — | Chặng bay |
| **Self-transfer** | — | Tự nối chuyến bằng vé riêng |
| **SSR** | Special Service Request | Yêu cầu dịch vụ đặc biệt |
| **Stop sell** | — | Ngừng bán |
| **Supplier / Principal** | — | Nhà cung cấp dịch vụ |
| **Take rate** | — | Doanh thu thuần / GBV |
| **TMC** | Travel Management Company | Công ty quản lý du lịch doanh nghiệp |
| **Tour operator** | — | Công ty tổ chức tour (lữ hành) |
| **TTL** | Ticketing Time Limit | Hạn xuất vé |
| **UGC** | User Generated Content | Nội dung do người dùng tạo |
| **VCC** | Virtual Credit Card | Thẻ ảo thanh toán cho nhà cung cấp |
| **White-label** | — | Cho đối tác dùng nền tảng dưới thương hiệu của họ |
| **Wholesaler** | — | Nhà bán buôn dịch vụ du lịch |
